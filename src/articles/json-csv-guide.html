给同事传数据,对方说要 CSV,你手上是 JSON——这两种格式到底啥关系?本文讲清区别与互转场景,文末附在线工具。

一、JSON 和 CSV 的本质区别

对比JSONCSV
结构嵌套层级,支持对象/数组扁平的二维表格
类型保留数字/布尔/null 类型全部是文本
可读性机器友好,人读略费劲Excel 直接打开,人读友好
体积较大(带键名和括号)紧凑(纯逗号分隔)
典型用途API 接口、配置文件、程序间传递Excel 导入导出、报表、数据分析

二、什么时候需要互转?

  • API 数据要分析:接口返回 JSON,放进 Excel/SPSS 前转成 CSV;
  • 报表要上线:运营给的 CSV 表要接入系统,转成 JSON 供程序读取;
  • 批量录入:把 JSON 里的数据转成表格人工核对。

👉 立即使用:在线 JSON/CSV 互转工具 —— 一键转换,支持下载文件,嵌套字段自动展平。

三、嵌套数据怎么办?

JSON 允许嵌套(对象里的对象、数组),CSV 只有两维。常见做法:

  • 对象嵌套:展平为点号字段,如 {"user":{"name":"张三"}} → 字段 user.name;
  • 数组:转成 JSON 字符串放进单元格,或用「多行」拆开。

互转工具一般默认展平对象,数组保留为 JSON 字符串,数据不丢失。

四、常见坑

CSV 里的逗号和引号

字段内含逗号时会被错误分列——正确做法是用双引号包裹(标准 CSV 规则),工具会自动处理。

中文乱码

CSV 用 Excel 打开乱码时,另存为 UTF-8 with BOM 即可;在线工具一般输出 UTF-8。

表头重复

CSV 转 JSON 时表头必须唯一,重复列名会导致数据覆盖。

总结:JSON 给程序、CSV 给表格;嵌套对象展平、数组留字符串,记住这两条互转就不踩坑。
