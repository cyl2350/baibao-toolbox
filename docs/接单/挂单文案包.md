## 通用建议

1. **闲鱼引流**:挂单 + 每天擦亮;首页展示工具站案例图(用 `docs/产品/详情图` 的思路,截图真实项目);
2. **报价技巧**:给区间不给死价,先聊需求再报价,「复杂程度不同价格不同」是标准话术;
3. **交付流程**:需求文档(双方确认)→ 报价 → 定金 → 开发 → 验收清单 → 尾款 → 售后;
4. **差评防御**:交付前主动演示,验收单写清楚「含 / 不含」,超范围需求单独加价;
5. **平台选择**:闲鱼流量最大;猪八戒 / 程序员客栈客单价高;微信社群转介绍转化最好。
