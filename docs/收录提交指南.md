# 搜索引擎收录提交指南(约 10 分钟,一次做完)

> 目的:让百度/谷歌收录网站,搜索「图片压缩」「房贷计算」等关键词时能被找到,带来免费流量 → 广告收入。
> 网站:sitemap 地址为 https://cyl2350.github.io/baibao-toolbox/sitemap.xml

---

## 一、百度收录(国内流量主力,优先做)

1. 打开 👉 https://ziyuan.baidu.com/ 用**百度账号**登录
2. 点「**用户中心 → 站点管理 → 添加网站**」
3. 输入:`https://cyl2350.github.io/baibao-toolbox/`
4. 选择**验证方式**:
   - 最简单:**HTML 标签验证** —— 把页面给的 `<meta name="baidu-site-verification" content="xxxx" />` 复制发给我
   - 或 **文件验证** —— 把页面给的验证文件名和内容发我
   - **我帮你把它部署到网站**后,回来点「完成验证」
5. 验证通过后,点「**普通收录 → sitemap**」,提交:`https://cyl2350.github.io/baibao-toolbox/sitemap.xml`
6. 顺带把网站首页地址也提交到「普通收录 → 链接提交」

## 二、谷歌收录(海外流量,顺手做)

1. 打开 👉 https://search.google.com/search-console 用 Google 账号登录
2. 添加资源,选「**网址前缀**」,输入:`https://cyl2350.github.io/baibao-toolbox/`
3. 验证方式任选:
   - **HTML 文件验证**:下载 Google 给的验证文件,把**文件名+内容**发我,我部署后回来点验证
   - 或 **HTML 标签**:把 meta 标签发我
4. 验证通过后,左侧「Sitemap」提交:`sitemap.xml`
5. (可选)「URL 检查」里粘贴首页地址,点「请求编入索引」

## 三、必应(可选,3 分钟)

bing.com/webmasters 提交同样 sitemap,国内也有部分用户用必应。

---

## 提交后会发生什么

- 百度:1 天~2 周开始收录,收录后搜索「百宝工具箱」「在线计算器」等可能找到你
- 谷歌:几小时~几天收录,新站收录较快
- 之后**每周有新页面,谷歌会自动爬取**(sitemap 自动更新);百度可每两周手动提交一次

---

## 需要发给我的东西(三种验证方式任选其一)

| 方式 | 你发给我什么 |
| --- | --- |
| 百度 HTML 标签 | 一整段 `<meta name="baidu-site-verification"...>` |
| 百度/谷歌 HTML 文件 | 文件名 + 文件内容 |
| 谷歌 HTML 标签 | 一整段 `<meta name="google-site-verification"...>` |
