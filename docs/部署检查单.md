# 部署检查单(30 分钟上线)

> 配合 `node scripts/check-deploy.mjs` 使用:先跑检查,再按本单执行。

## 第 1 步:修改配置(5 分钟)

编辑 `config/site.mjs`,共 3~5 处:

| 配置项 | 现在 | 改成 |
| --- | --- | --- |
| `domain` | `www.baibao-toolbox.example` | 你的真实域名(如 `www.xxx.com`;没有域名就先填 Cloudflare Pages 给的 `xxx.pages.dev`) |
| `email` | `contact@example.com` | 你的真实邮箱 |
| `monetization.adsenseClient` | 空 | AdSense 审核通过后填入(可后补) |
| `monetization.taokeUrl` | 空 | 淘宝客推广链接(可后补) |
| `analytics.*` | 空 | 百度统计 / GA4 ID(可后补) |

> 可后补的项不影响上线,上线后再改再 `node build.mjs` 即可。

## 第 2 步:构建 + 检查(2 分钟)

```bash
node build.mjs          # 重新生成 dist/
node scripts/check-deploy.mjs   # 检查应全部 OK 或只有 ℹ️ 信息项
node server.mjs 8080    # 本地预览 http://127.0.0.1:8080/ 点开几个工具试试
```

## 第 3 步:推送 GitHub 自动部署(10 分钟)

1. 注册/登录 [github.com](https://github.com),新建仓库(Public 即可),名称如 `baibao-toolbox`;
2. 在项目目录执行:
   ```bash
   git remote add origin https://github.com/<你的用户名>/baibao-toolbox.git
   git push -u origin master
   ```
3. 仓库 Settings → Pages → **Source 选 "GitHub Actions"**(已配置好工作流,推送后自动构建部署);
4. 等 1~2 分钟,访问 `https://<用户名>.github.io/baibao-toolbox/`;
5. 若已有自定义域名:仓库根目录建 `CNAME` 文件写域名,并在域名商解析 CNAME。

> 也可以不用 GitHub:把 `dist/` 文件夹直接拖进 [Cloudflare Pages](https://pages.cloudflare.com) 上传,同样免费。

## 常见问题

**Q:没有域名可以上线吗?**
可以。Cloudflare Pages / GitHub Pages 都提供免费子域名,先用免费域名上线,SEO 起来后再换正式域名。

**Q:国内打不开 GitHub Pages 怎么办?**
用 Cloudflare Pages(国内相对稳定),或部署到国内服务器(需备案,备案后再接百度联盟)。

**Q:部署后怎么确认生效?**
浏览器打开域名,能打开首页、任意工具页、`/sitemap.xml` 即成功;再跑一次 `node scripts/check-deploy.mjs` 确认 domain 不再是 example。
