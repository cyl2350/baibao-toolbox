## 🏗 第 1 步:网站上线(10 分钟)

```powershell
cd D:\项目\项目1\baibao-toolbox
# 1. 打开 config/site.mjs,把 domain 和 email 里的 example 改成你的真实信息
# 2. 一键构建 + 自检 + 预览:
node build.mjs
node scripts/check-deploy.mjs   # 应全部 ✅(只剩域名/邮箱 2 条提醒)
node scripts/launch.ps1         # 或直接运行,自动完成上面两步并打开预览
```

**推送 GitHub 上线(3 条命令):**
```powershell
# GitHub 新建仓库后(名字随意,如 baibao-toolbox):
git remote add origin https://github.com/你的用户名/baibao-toolbox.git
git push -u origin master
# 仓库 Settings → Pages → Source 选 "GitHub Actions" → 等 2 分钟上线
# 不用 GitHub 也行:把 dist/ 文件夹拖进 cloudflare.com/pages 上传,同样免费
```

**提交收录 + 广告:**
- 百度搜索资源平台(ziyuan.baidu.com)提交 `https://你的域名/sitemap.xml`
- Google Search Console 提交同一个 sitemap
- Google AdSense 提交申请(网站已 16/16 合规,含隐私政策页)
