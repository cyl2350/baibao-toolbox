# 🤖 闲鱼账号 AI 全自动代运营方案

> 一句话:AI 包办「写文案、回话术、排任务、记台账、做复盘」,闲鱼官方功能包办「自动发货、自动回复」,你只保留最后的「一键上架/擦亮」——每天 10 分钟,账户零风险。

---

## 一、为什么不能做成「机器人全自动挂机」

你最初的想法是让 AI 全自动登录、自动发布、自动聊天。这个方向**必须放弃**,原因是硬约束:

| 约束 | 说明 |
| --- | --- |
| 平台风控 | 闲鱼对非官方自动化有强风控(滑块验证、设备指纹、行为检测),机器人操作会触发限流/降权/封号 |
| 平台协议 | 使用脚本/模拟器自动化违反闲鱼用户协议,封号后账号内资金与信誉不可恢复 |
| 登录凭证 | 我无法替你保管手机号验证码/登录态;明文保存账号密码本身就是风险 |
| 实时聊天 | 自动回复机器人回复错误会得罪买家、引发纠纷,平台会判责 |

**结论:真正的「全自动」= 能自动的全自动 + 不能自动的人只点一下。** 这套方案已按此原则落地。

## 三、每日自动化流程(照做即可)

```
早上 5 分钟  工作台「任务」页 → 擦亮 6 件商品(闲鱼 App) → 看曝光
中午 5 分钟  话术页搜索「询价/砍价」→ 复制粘贴回复买家
晚上 10 分钟 台账页记一笔 → 未读买家跟进 → 复盘:咨询<3 就降价/改标题
每周 30 分钟 小红书引流笔记 1~2 条(docs/运营/小红书引流笔记.md 有现成) → 周复盘调价
```

## 四、关键设置(一次 10 分钟,做完就是真"全自动发货")

1. 闲鱼 App → 发布虚拟商品时选「自动发货」,填入百度网盘链接 + 提取码;
2. 以后每笔成交,闲鱼系统自动把网盘链接发给买家,**发货环节 0 人工**;
3. 自动回复设置:闲鱼 App → 我的 → 设置 → 自动回复,粘贴 `回复话术库.md` 里的通用开场白;
4. 网盘链接+密码记在手机备忘录,`config/xianyu.mjs` 里同步更新。

## 六、合规红线(不可触碰)

- ❌ 不写登录脚本、不模拟点击、不挂机自动回复、不买"闲鱼助手"类外挂;
- ❌ 标题/描述不用「最」「第一」「百分百」「绝对」等广告违禁词;
- ✅ 只卖原创/AI 生成内容;虚拟商品写清「网盘发货」;
- ✅ 收款只走闲鱼官方交易,绝不私下转账。
