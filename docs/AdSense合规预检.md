## 二、待你操作项

1. **填入真实域名** → `config/site.mjs` 的 `domain`,重新 `node build.mjs`;
2. **部署并启用 HTTPS**(Let's Encrypt / Cloudflare 免费证书均可);
3. **提交申请**[Google AdSense](https://adsense.google.com),用有内容的网站地址(如 `https://你的域名/` 而非工具子页);
4. 审核通常 1~14 天,期间保持网站可访问、不要大改结构。

## 三、AdSense 审核要点备忘(人工复查用)

- **内容**:每个工具页都有独立原创描述与使用说明(已满足);建议持续增加文章,丰富度越高越稳;
- **导航**:全站内链(头部导航 + 页脚 + 相关工具 + 文章互链)已具备;
- **广告位**:本项目每页预留 2 个广告位,布局符合「内容为主、广告为辅」的规范;
- **合规**:不诱导点击、不加伪装关闭按钮、广告与内容明显区分(当前广告位为独立区块);
- **隐私**:隐私政策已覆盖「本地处理 + 第三方 Cookie」说明。
