# 公众号排版速查表

> 自媒体人必备的排版手册:字号、行距、配色、标题、工具一站查齐,照着调就能出专业排版。
> 使用说明:把【】替换为你的文章内容;配色按「1 主色 + 1 辅助色 + 1 强调色」原则搭配。

## 一、核心参数速查(最常用)

1. **正文字号**:15px ~ 16px(推荐 15px,长文用 16px 更护眼)。
2. **标题字号**:18px ~ 24px(小标题 18px,大标题 22~24px)。
3. **行距(行高)**:1.75 倍(推荐);手机端阅读 1.6~1.8 倍最佳。
4. **字间距**:0.5px ~ 1px(正文 0.5px,标题 1px)。
5. **段间距**:段前段后各 15~20px,或空一行。
6. **页边距**:左右各 15~20px(编辑器默认即可)。
7. **缩进**:正文首行不缩进(新媒体习惯),段落间用空行分隔。
8. **对齐方式**:正文两端对齐,标题居中或左对齐,风格统一即可。

## 二、配色方案(6 套现成色板)

9. **经典商务**(蓝灰):主色 #2F5AF3 / 辅助 #64748B / 强调 #F59E0B,适合职场、科技、财经。
10. **温柔治愈**(莫兰迪粉):主色 #D4A5A5 / 辅助 #A8B5A2 / 强调 #8D6E63,适合情感、生活、心理。
11. **清新自然**(绿):主色 #10B981 / 辅助 #6EE7B7 / 强调 #FBBF24,适合健康、美食、环保。
12. **高级暗调**(黑金):主色 #111827 / 辅助 #6B7280 / 强调 #D97706,适合深度、职场干货。
13. **活力橙红**:主色 #FF6B35 / 辅助 #FFD166 / 强调 #EF476F,适合活动、促销、时尚。
14. **简约黑白灰**:主色 #1F2937 / 辅助 #9CA3AF / 强调 #EF4444,任何领域都不会错。
15. **配色原则**:全文主色占比 70%、辅助 20%、强调 10%;文字颜色用深灰 #333 或 #1F2937,不用纯黑 #000。

## 三、标题公式与规范

16. **标题字数**:15~20 字最佳,太长会被折叠;数字与问句点击率高。
17. **小标题层级**:一级「一、」二级「1.」三级「(1)」,层级不超过三级。
18. **标题样式**:小标题加粗 + 主色 + 前后留白,不滥用表情符号。
19. **封面标题**:封面图上的字 6~8 字以内,字号覆盖图宽 60% 以上。
20. **爆款标题模板**:数字型(「3 个方法」)、痛点型(「别再…了」)、悬念型(「为什么…」)、身份型(「写给…的你」)。

## 四、排版工具推荐

21. **135 编辑器**:模板多、上手快,适合新手。
22. **秀米**:自由排版能力强,适合想做专属风格的用户。
23. **壹伴 / 新媒体管家**:浏览器插件,素材库 + 排版增强。
24. **Markdown 编辑器**:程序员友好,纯文本写稿,一键转排版(本站提供免费在线版)。
25. **Canva / 稿定设计**:封面图、头图、引导关注图在线制作。
26. **图片工具**:在线压缩(本站提供)保证封面不超 10M。

## 五、素材与组件清单

27. **必备组件**:头图、引导关注卡片、正文分隔线、重点强调框、引用块、文末「在看/点赞」引导、二维码名片。
28. **分隔线风格**:细线 + 居中图标(如 ◆)或留白即可,花哨分隔线容易显廉价。
29. **强调框用法**:只强调最关键的 1~2 句话,整段标色等于没标。
30. **引用块**:长引用用灰色底 + 左边线;短引用用主色加粗即可。

## 六、常见错误自查(发布前过一遍)

31. **字号过大或过小**:正文 ≥17px 显笨重,≤13px 伤眼。
32. **颜色超过 4 种**:红黄蓝绿堆一起,专业感归零。
33. **行距过窄**:1.2 倍行距手机端读起来像天书。
34. **全篇加粗标色**:重点太多 = 没有重点。
35. **图片模糊/超时**:封面压到 900×383px 以内、500KB 以下。
36. **段落过长**:手机上一段超过 5 行就要考虑拆段。
37. **标点混用**:中英文标点统一,中文文章用全角标点。
38. **错别字与敏感词**:发布前用工具检查敏感词与错别字。

## 七、发布前检查清单

39. **内容**:标题 + 摘要(可选)+ 正文无错别字 + 图片可显示。
40. **排版**:字号行距统一 + 配色一致 + 重点突出。
41. **互动**:文末引导语 + 话题标签(如果平台支持)。
42. **合规**:无违禁词、无侵权素材、广告法合规(不用「最」「第一」)。

---

## 排版黄金法则

> 排版的目标是让读者「无痛读完」:一屏信息量适中、重点一眼可见、整体风格统一。
> 记住公式:舒服的字号 + 足够的留白 + 克制的配色 + 清晰的层级 = 专业排版。
