# 简历模板 + 面试话术包

> 求职季自救指南:简历模板 + 用词库 + 自我介绍 + 20 道高频面试题答题框架 + 谈薪话术。
> 使用说明:【】内为需要替换的内容;简历用 STAR 结构(情境-任务-行动-结果)最能打动 HR。

## 一、简历黄金结构(照着填)

1. **基本信息**:姓名 / 求职意向【岗位】/ 电话 / 邮箱 / 城市 / 到岗时间 / 作品链接(如有)。
2. **个人优势(3 条)**:每条 15 字内,突出【行业年限 + 核心技能 + 代表成果】。
3. **工作经历(倒序)**:公司-职位-时间;每条用 STAR:情境(背景)→ 任务(目标)→ 行动(你做了什么)→ 结果(数据化)。
4. **项目经历**:挑 1~2 个最亮眼的,格式同工作经历,附【规模/结果/你的角色】。
5. **教育背景**:学校-专业-时间,应届生加【GPA/主修课程/荣誉】。
6. **技能证书**:与岗位相关的放前面,如【软件工具 / 语言 / 证书 / 数据分析能力】。

## 二、简历用词库(替换平庸表达)

7. **负责→主导/独立负责/深度参与**:「负责公众号运营」→「独立运营公众号,粉丝 0→5 万」。
8. **协助→支持/协同推进**:突出你的主动性。
9. **提高→提升/优化/增长**:「提高了效率」→「优化流程,效率提升 40%」。
10. **完成→超额完成/提前交付**:「完成 KPI」→「提前 2 周超额完成季度 KPI」。
11. **数字公式**:动词 + 对象 + 动作 + 结果(数字):「搭建用户分层体系,复购率提升 25%」。
12. **结果动词**:实现/达成/突破/拿下/获得/推动/落地/沉淀/赋能。

## 三、自我介绍模板(1 分钟版)

13. **公式**:「面试官好,我是【姓名】,【年限】年【岗位】经验,上一份工作在【公司】负责【核心职责】,期间【最亮眼成果,带数字】。我应聘贵司【岗位】,是因为【与岗位的匹配点 + 对公司的认可】。我的优势是【2 个关键词】,希望能有机会加入团队。」。
14. **应届生版**:「我是【学校】【专业】应届生,【实习/项目】经历让我掌握了【技能】,【竞赛/成果】验证了我的【能力】,期待在贵司把这份热情落地。」。
15. **转行版**:「我原从事【行业】,因为【原因】选择转向【岗位】,已系统学习【技能】,并做了【作品/项目】,我认为过往的【可迁移能力】能带来差异化价值。」。

## 四、高频面试题 20 问(答题框架)

16. **「自我介绍」**:见上文公式,控制在 60~90 秒,突出与岗位的匹配。
17. **「为什么选择我们公司」**:行业前景 + 公司业务/文化认可 + 岗位与我的匹配,提前查官网/新闻。
18. **「你的优缺点」**:优点 2 个(带证据);缺点 1 个真实但不致命的(如「容易过度追求细节,现在会用优先级清单管理」)+ 改进动作。
19. **「你的期望薪资」**:给区间(底价~理想价),强调「更看重平台与成长,但期望与能力匹配」。
20. **「为什么离开上一家」**:不谈负面,讲成长诉求(「希望接触更大体量业务」)。
21. **「你最大的成就」**:用 STAR + 数据,选与岗位相关的。
22. **「你最大的失败」**:讲可控失误 + 复盘 + 之后如何避免,展现成长型思维。
23. **「能接受加班吗」**:「理解业务高峰期需要投入,我会通过提升效率减少无效加班」。
24. **「你还有什么想问的」**:问岗位考核标准 / 团队结构 / 入职后 3 个月目标,体现主动性。
25. **「职业规划」**:3 年内深耕【岗位方向】成为专家,与公司共同成长。
26. **「如何看待压力」**:举例说明你如何在高压下交付结果。
27. **「你的空窗期在做什么」**:学习新技能 / 复盘 / 项目实践,证明你一直在成长。
28. **「团队冲突如何处理」**:先沟通对齐目标 → 求同存异 → 以结果为导向。
29. **「为什么你的专业不对口」**:可迁移能力 + 自驱学习 + 实际作品。
30. **「给你一个任务你会怎么做」**:拆解目标 → 排优先级 → 找资源 → 小步验证 → 复盘。
31. **「你了解我们产品吗」**:提前做功课,说出 2~3 个亮点 + 1 个可改进点。
32. **「接受 base 城市吗」**:明确答复 + 理由,犹豫会扣分。
33. **「你目前手里有其他 offer 吗」**:如实但给期限感(「还有一个流程中,但我对贵司意向更强」)。
34. **「你的离职交接期多久」**:说清楚可到岗时间,体现职业素养。
35. **「还有什么要补充的吗」**:强调 1 个最匹配岗位的优势 + 表达诚意。

## 五、谈薪与 offer 沟通

36. **谈薪三原则**:先听对方出价 / 不暴露底价 / 给区间并留协商空间。
37. **接受 offer 回复**:表达感谢 + 确认薪资结构与到岗时间(五险一金基数、试用期折扣要问清)。
38. **婉拒 offer**:感谢 + 简短理由(「经过慎重考虑,选择更匹配的机会」)+ 保持人脉。
39. **入职前确认清单**:合同条款 / 试用期时长与薪资 / 社保缴纳基数 / 绩效考核方式。
40. **离职交接模板**:工作交接清单 + 时间表 + 联系方式,留个好印象圈子很小。
