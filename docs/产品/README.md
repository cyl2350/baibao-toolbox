## 生成命令

```bash
# 需要先安装依赖(一次性)
npm i

# 重新生成单个产品
npm run pdf:handbook   # AI 提示词实战手册
npm run pdf:xhs        # 小红书爆款文案模板库
npm run pdf:resume     # 简历模板 + 面试话术包
npm run pdf:gzh        # 公众号排版速查表
npm run pdf:scripts    # AI 自动化办公脚本合集
npm run img            # 重新生成全部详情图
```
