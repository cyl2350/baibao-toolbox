# AI 自动化办公脚本合集

> 30+ 个可直接运行的自动化脚本与思路,覆盖文件批处理、Excel、网页数据、定时提醒四大场景。
> 使用说明:脚本以 Python 为主(需要安装 Python 3),注明「零依赖」的用系统自带能力即可运行;【】为需要替换的位置。

## 一、文件批量处理

1. **批量重命名(零依赖)**:按规则重命名文件夹内所有文件,支持序号、日期前缀:【示例】`file_01.jpg`。核心代码:`for i, f in enumerate(files): os.rename(f, f'{prefix}_{i:02d}{ext}')`。
2. **按类型整理文件(零依赖)**:把下载文件夹按扩展名自动分到 图片/文档/压缩包/其他 子目录,`shutil.move` 循环即可。
3. **批量删除重复文件**:按文件内容 MD5 去重,保留第一份,清理网盘/电脑重复文件:`hashlib.md5` 计算后放入 dict。
4. **批量压缩图片**:用 Pillow 把文件夹内所有图片压缩到指定宽高与质量,网页/邮件用图神器。
5. **批量转换格式**:Word→PDF 用 `docx2pdf`;图片格式转换用 Pillow;CSV→Excel 用 pandas,一键批量。
6. **批量修改文件名日期**:把文件名中的中文日期(2024年1月1日)统一为 `2024-01-01`,正则替换。
7. **自动归档旧文件**:把超过 90 天未修改的文件移动到「归档」文件夹,保持工作目录清爽。

## 二、Excel 自动化

8. **多表合并(零依赖)**:把文件夹内所有 Excel 的第 1 个 sheet 合并成一个总表,`pandas.concat` 一行搞定。
9. **数据去重与清洗**:按指定列去重、去空格、统一日期格式、空值填充,`df.drop_duplicates()` 等。
10. **工资表转工资条**:一张总表拆成每行一个人的工资条,自动插入表头,`for i in range(len(df))` 切片写入。
11. **VLOOKUP 批量替代**:两表按工号/姓名匹配,把 B 表字段填到 A 表,`df.merge()` 比 VLOOKUP 快且不卡。
12. **报表自动生成**:每日数据粘贴进模板表,自动汇总本周/本月同比环比,`groupby + pivot_table`。
13. **Excel 批量加批注 / 标色**:按条件给单元格标色(如逾期红色),`openpyxl` 的 `PatternFill`。
14. **拆分大表**:把 10 万行大表按「部门/日期」拆成多个小表,每个一个文件,`groupby` 后循环保存。
15. **把 PDF 表格提取到 Excel**:`pdfplumber` 提取表格文字,清洗后写入 Excel,替代手工录入。

## 三、网页与数据

16. **批量下载网页图片**:按规则抓取页面里所有图片(如壁纸、产品图),`requests + BeautifulSoup`。
17. **表格网页转 Excel**:把网页上的数据表格一键抓成 Excel,`pandas.read_html(url)` 零 JS 页面直接可用。
18. **定时检查价格/库存**:每分钟访问商品页,价格变动自动记录并提醒,`requests` + 定时器。
19. **新闻/公告监控**:定时抓取官网公告,出现新内容自动通知,`requests + 关键词匹配`。
20. **Excel 批量发邮件**:按表里的收件人/主题/附件逐行发送邮件(企业邮箱),`smtplib` + `openpyxl`。
21. **网页填表自动化(进阶)**:用 Selenium 自动登录、填表、提交,适合内网重复录入场景。
22. **公众号文章导出**:把文章链接批量抓取正文与图片保存为 Markdown,`requests + lxml`。

## 四、定时与提醒

23. **桌面弹窗提醒(Windows,零依赖)**:到点弹窗「该喝水/站起来」,`win10toast` 或 `msg` 命令。
24. **邮件定时提醒**:每天 9 点自动把待办事项发到邮箱,`schedule` 库 + smtplib。
25. **微信/钉钉推送提醒**:用 Server酱(方糖)或钉钉机器人 webhook,一行 `requests.post` 推送到手机。
26. **文件自动备份**:每天定时把工作目录压缩备份到另一个盘/网盘目录,`zipfile + schedule`。
27. **待办任务提醒**:读取待办 CSV,到期前 1 天推送提醒,`datetime` 判断即可。
28. **电脑自动关机/待机计划**:到点自动执行系统命令(`shutdown -s -t 0`),适合下载完自动关。

30. **批量压缩图片模板**:15 行完整代码,指定文件夹、输出质量,一次处理上千张。
31. **多表合并模板**:15 行完整代码,合并一个文件夹里所有 Excel 到一个总表。

33. **网页表格抓取模板**:12 行完整代码,把任意静态表格网页抓成 Excel。
34. **邮件群发模板**:25 行完整代码,支持附件与收件人列表,注意企业邮箱授权码。
