## 二、主线:部署 + 广告变现

### 2.1 部署(三选一,推荐顺序)

**方案 A:Cloudflare Pages(免费,推荐新手)**
1. 注册 [cloudflare.com](https://cloudflare.com)(免费),把 `dist/` 文件夹拖入 Pages 上传,或连接 GitHub 仓库自动部署。
2. 免费获得 `xxx.pages.dev` 子域名;要自己的域名再绑定(域名约 ¥50~80/年)。
3. 优点:免费、全球 CDN、国内部分地区可访问。

**方案 B:GitHub Pages(免费)**
1. 把 `baibao-toolbox` 推送到 GitHub 仓库,Settings → Pages → 选择分支,开启。
2. 得到 `https://<用户名>.github.io/baibao-toolbox/`。
3. 注意:项目页部署在子路径,本项目的相对路径引用已兼容,可直接用。

**方案 C:国内云服务器(需要 ICP 备案才能用百度联盟)**
1. 阿里云/腾讯云轻量服务器(约 ¥100/年)+ 域名。
2. 备案约 2~4 周;备案通过后可申请百度联盟。
3. 把 `dist/` 用 Nginx 部署:`server { root /var/www/baibao; index index.html; }`。

> 部署后务必:① 把 `config/site.mjs` 的 `domain` 改成真实域名并重新 `node build.mjs`;② 在搜索引擎提交收录(见 2.4)。

### 2.2 接入广告

**Google AdSense**(无备案也能申请)
1. 注册 [adsense.google.com](https://adsense.google.com),网站需有内容(本项目的 17 个工具页 + 3 个内容页已满足)、需有**隐私政策页**(已内置 `/privacy/`)。
2. 审核通常 1~14 天。通过后在后台创建「自适应广告单元」,把发布商 ID(形如 `ca-pub-xxxxxxxx`)填入 `config/site.mjs` 的 `monetization.adsenseClient`,重新构建部署。
3. 每个页面已预留 2 个广告位(工具页顶部+底部、首页 2 个横幅),代码自动切换为真实广告。

**百度联盟**(需备案域名)
1. 备案通过后注册 [union.baidu.com](https://union.baidu.com),创建广告位,把广告位 ID 填入 `monetization.baiduAdUnit`。
2. 百度联盟对国内流量单价更高,建议备案后主用。

**淘宝客(阿里妈妈)**
1. 注册 [pub.alimama.com](https://pub.alimama.com)(需淘宝账号),选品生成推广链接。
2. 把链接填入 `monetization.taokeUrl`,在工具页底部「推荐」区域展示。适合「办公用品」「数码周边」等与工具站用户重合的品类。

### 2.3 收入预期(现实版)

- 工具类长尾词流量低但转化意图明确,单次点击广告收入约 ¥0.5~2(国内百度联盟更高)。
- 收录 + 积累期约 1~3 个月;之后每个工具页每天可能带来 5~50 次访问。
- 粗略估算:**日 UV 1000 ≈ 月收入 ¥150~500**。想加速:多铺工具(每加 1 个工具=多一个关键词页面)+ 持续写「工具使用教程」文章页。

### 2.4 SEO 增长清单(上线第 1 周必做)

1. **百度搜索资源平台**(ziyuan.baidu.com)注册,提交站点 + sitemap 链接 `https://你的域名/sitemap.xml`;并添加「自动推送」JS(把 `site.analytics.baiduTongjiId` 填上后,构建已自动注入推送代码)。
2. **Google Search Console**(search.google.com/search-console)同样提交 sitemap。
3. 内链已自动做好(每个工具页有「相关工具」区块);后续写教程文章时互相链接。
4. 每 1~2 周新增 1~3 个工具,让 sitemap 持续更新,告诉搜索引擎「站点是活的」。
5. 移动端体验:本项目已适配手机,百度对移动友好站点有收录加成。

## 三、快线 A:闲鱼 / 小红书数字产品(最快见钱)

工具站需要时间积累流量,而**数字产品几乎零成本、当天可上架、几天内可能开单**。用本站定位做内容背书,同时做数字产品,两条腿走路。

**推荐产品(下一步我直接帮你生成成品文件):**
1. 《AI 提示词实战手册》—— 100+ 精选提示词(写作/职场/学习/编程),PDF 版。
2. 《小红书爆款文案模板库》—— 50 个可直接套用的模板。
3. 《简历模板 + 面试话术包》。
4. 《公众号排版速查表》。

**发布 SOP(闲鱼):**
1. 标题带关键词:「AI提示词手册 PDF 网盘发货 100个场景直接抄」。
2. 定价 ¥2.9~9.9(前期跑量),描述里放目录截图 3~5 张。
3. 自动发货:闲鱼支持网盘链接自动回复;或用「虚拟卡密」。
4. 每天擦亮 1 次 + 回复询价秒回,30 天内同品类上 3~5 个链接测款。
5. 小红书同步发「干货截图 + 评论区引导」。

> 合规提示:虚拟资料需自行保证版权(只卖自己原创/AI 生成内容);遵守平台虚拟商品规则。

## 六、合规与风险

- **隐私**:本站不收集用户数据,隐私政策页已就位,满足 AdSense 要求。
